# Paradise Nursery Shopping App

Paradise Nursery is a plant shopping storefront built with React and Redux. The app allows users to browse indoor plants, view product details, add items to the cart, and manage quantities in the shopping cart.

## Features

- Home page with Paradise Nursery branding and a Get Started CTA
- Product listing grouped by plant categories
- Add to Cart interactions with disabled button states
- Cart quantity tracking and total amount calculations
- Global cart state using Redux Toolkit
- Responsive layout for desktop and mobile screens

## Run locally

```bash
npm install
npm run dev
```

## Deployment

```bash
npm run deploy
```
